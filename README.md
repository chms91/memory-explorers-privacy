# Memory Explorers privacy policy

This repository publishes the bilingual privacy policy for the Memory Explorers Android app through GitHub Pages. The page is the root `index.html`; `.nojekyll` serves that file as written.

For updates, copy the reviewed policy from the app project's `docs/play-assets/privacy-policy.html` to `index.html`, commit and push to `main`, then verify the public page and the URL entered in Google Play Console.
